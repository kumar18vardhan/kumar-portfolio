## 📌 About the Project

This is my personal portfolio website, designed to present my technical skills, academic background, and projects in a clean and organized interface.

The website provides an overview of my profile and includes links to my resume and professional platforms.

## ✨ Features

* 👨‍💻 Personal profile section

* 🎓 Education section
* 💼 Projects showcase
* 📄 Resume access

## ▶️ Run Locally

Clone the repository:

```bash
git clone https://github.com/kumar18vardhan/kumar-portfolio.git
```

Go to the project directory:

```bash
cd kumar-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will run on the local development server. Open the URL shown in your terminal.
